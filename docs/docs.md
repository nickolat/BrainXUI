# DOCS

Implementation details are explained here.


### Desikan-Killiany Atlas

The file `save_atlas.py` fetches the Desikan-Killiany brain atlas
from `abagen` library and extracts left and right hemisphere surface. Then,
the surfaces are saved in the form of numpy arrays.

### Loading and preprocess

In `main.py` there is a first loading and preprocessing step:
* the atlas surfaces are loaded, 
* the csv shap files are transformed into pandas dataframes
* the FSAVERAGE brain surface meshes are fetched from `nilearn` library
* An array that contains the indexes of the atlas is created
* patient IDs and shap values are stored in numpy arrays, while
demographic data is stored in a dictionary: {partecipant_id: [sex, age, site]}

### Mapping between surface regions and shap values

To show the shap values for each region in the 3d view of the brain surface, 
I created a mapping between surface coordinates and shap values.
This mapping is done in `get_surf_shap()` function inside `utils.py`.
This function returns left and right numpy arrays which contain a shap
value for each of the 3d coordinates of the corresponding surface mesh.

In order to show the anatomical name of the brain regions,
I created a similar mapping between surface coordinates and region labels,
in `get_surf_labels()` function.

### Plot

To create the plot I used `nilearn` library that provides useful functions to
plot brain images, surfaces and volumes in different ways.

In particular, I used the function `plot_surf_stat_map()` to plot an interactive
3d visualization of a brain surface for one hemisphere at a time,
using the FSAVERAGE mesh and the mapping between coordinates and shap values.
The shap values are shown on the regions in the form of different colors, 
using 'seismic' colorbar, ranging from blue (low value) to red (high value).
Then, I customized the plot using `plotly` library.

The function `update_figure_layout()` in `utils.py` customizes the layout of the plot
and adds a hover label that shows the region name and the shap value
associated to that region, for each point in the 3d plot.


### Interface

To create a visual interface, I used `panel` library and
the FastGridTemplate, which is composed of 2 main parts: main and sidebar.

The main part contains the plot generated by nilearn and plotly.

The sidebar contains:
* 3 dropdown menus to select: SHAP data, patient ID and hemisphere
* Demographic data of selected patient

There is also a toggle to hide the sidebar and expand the brain visualization.

In particular, the `update_graph()` function is called every time the user
select an option in the dropdown menus. This functions builds the 
corresponding plot and shows it in the main area of the interface.

The `update_demo_data()` function shows the demographic data in the
sidebar, and it is called every time the user selects a new patient ID.

The resulting interface is clean and contains only the useful information.
